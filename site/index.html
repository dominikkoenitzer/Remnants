Remnants

A code editor built on the open VS Code source, with every AI feature taken out. Nothing asks you to sign in, and it sends no usage data.

Download for Windows

Also for Windows on ARM, macOS and Linux.

The Windows installer is just for you and needs no admin rights.

If Windows says it protected your PC, click More info, then Run anyway.

Remnants runs on Windows, macOS and Linux. Open this page on your computer to download it.

Layout

Views live in the status bar

The activity bar is hidden, so the editor gets the room. Explorer, Search, Source Control, Run and Debug and Extensions sit at the left of the status bar, the terminal and settings at the right.

The switch of the open view is lit.

Diff

See every change side by side

Click a changed file in Source Control and Remnants opens it next to the last commit. Removed text is marked on the left, added text on the right.

Terminal

Your shell, right under the code

The terminal opens in the panel below the editor and starts your shell in the project folder. Ctrl+` shows or hides it.

Search

Find text across the project

Search lists every match, grouped by file, with a count per file. Ctrl+Shift+F opens it, and a click on a match opens the file at that line.

Extensions

Extensions from Open VSX

The Extensions view searches and installs from Open VSX, the open registry for editor extensions. Your languages and themes work as you know them.

Themes

Light and dark, as you like

A light and a dark theme come with it, and any theme from Open VSX works too.

  • About 175 MB to download on Windows

Privacy

No AI and no telemetry

The chat panel, agent sessions, voice features and the built-in AI extension were removed from the source. Telemetry and crash reports are off, and there is no sign-in.

Extension searches and updates go to Open VSX. The release check is off until you turn it on.

Your data

Settings stay when you update

Settings and keybindings live in %APPDATA%\Remnants on Windows, ~/Library/Application Support/Remnants on macOS and ~/.config/Remnants on Linux. Extensions live in ~/.remnants/extensions.

Get started

  1. Download the installer.
  2. Double-click it and follow the setup.
  3. Open a folder and start coding.
02

Updates

Remnants never updates itself. Install the new release over the old one; settings and extensions stay. Turn on remnants.checkForUpdates to hear about new releases.

03

Removing it

On Windows, uninstall it under Settings, Apps. On a Mac, move it to the Trash. On Linux, remove the package. Your settings folder stays until you delete it.

Questions

Is Remnants free?

Yes. It is free and open source under the MIT License, with no account.

Why does Windows say it protected my PC?

Remnants is not signed with a paid certificate, so Windows asks once. Click More info, then Run anyway. Every download has a checksum in the checksum file.

Does it have any AI features?

No. They were removed from the source, not just switched off, and telemetry is off too.

Which files are there for macOS and Linux?

macOS: a disk image for Apple silicon and for Intel.

Linux: a .deb for Debian and Ubuntu, an .rpm for Fedora and openSUSE, a tarball for any distribution, and a PKGBUILD for Arch.

Where are my settings and extensions?

Settings live in %APPDATA%\Remnants on Windows, ~/Library/Application Support/Remnants on macOS and ~/.config/Remnants on Linux. Extensions live in ~/.remnants/extensions. Uninstalling leaves both in place.

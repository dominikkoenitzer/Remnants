Remnants

A code editor built on the open VS Code source, with every AI feature taken out.

Download for Windows

Also for Windows on ARM.

If Windows says it protected your PC, click More info, then Run anyway.

Remnants runs on Windows. Open this page on your Windows PC to download it.

What it does

  • Nothing asks you to sign in.
  • The terminal, version control, the debugger and the usual shortcuts work as you know them.
  • You can still add extensions for your languages and themes.
  • It sends no usage data. New versions come from this page.
  • It installs just for you, so you need no admin rights.
